# 验证与报告

## 离线回归

```sh
node --test tests/*.test.mjs
```

测试使用合成Protobuf和临时SQLite，不读取真实用户会话。覆盖：真实分母256k/983k/缺失、缓存输入、最新调用、损坏数据、只读、请求范围、HTTP/Connect/gRPC-Web/WebSocket封装、恢复、重复安装与独立临时安装目录。

## 本机验收

| 检查 | 证据 | 失败时处理 |
| --- | --- | --- |
| 高对比主题 | 主区#FCFCFB、侧栏#F7F5F0、输入框#F9F7F2 | 核对Light模式和选择器，不改原包 |
| 字体 | FontFace真实加载/平台字体结果 | 重启字体缓存；缺字体标明回退 |
| 汉化 | 导航翻译，受保护区内容不变 | 修正排除范围；不能“全页替换英文” |
| 菜单覆盖 | audit主包差量结果 | 如实保留未翻译项，不承诺零遗漏 |
| 设置弹窗 | 正常打开且路由state保留 | 撤回不兼容事件增强 |
| 指标 | 同次调用usage与max_context_tokens | 无预算不猜百分比 |
| 宽窄布局 | 指标位于模型与发送区之间，极窄时跳行 | 停用该模块并报告未通过 |
| 1M普通界面 | 正常点击发送；请求值+最终执行配置+调用预算 | 请求包装未命中则检查实际协议 |
| 重启 | 完全退出重开，服务恢复，首页新会话再次发送 | 区分旧会话保留参数与真正默认生效 |
| 关闭1M | 配置false、重启服务和客户端；包装不再存在 | 不能只改文件就宣称即时恢复 |
| 其他模型 | 不修改未知/其他模型请求 | 拒绝泛化模型匹配规则 |

不要为了验证而向用户正在工作的会话注入测试消息；使用用户授权的独立验收会话，通过正常界面创建，不读取项目、不调用工具。重启前先确认本机没有进行中的任务。不要发送近百万tokens作为默认测试，它会增加延迟和额度。

## 报告模板

记录客户端版本、Node版本、补丁开关、配色、语法/测试结果、实际协议、模型标识、请求窗口、最终预算、输出预留、普通界面与重启验证结果、未验证项、备份与恢复路径。

发布到GitHub的报告只包含去标识后的数值和结果，不包含用户会话ID、个人路径、邮箱、凭证、真实消息或截图。
